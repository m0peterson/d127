# d127: цитата дня

Тапаешь кнопку, одновременно бросаются страница (d127) и строка (d3), по результату из сборника достаётся цитата дня в духе Стэтхема. Мобильное веб-приложение: работает на любом устройстве, ставится на домашний экран, открывается без сети.

## Деплой в один клик

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/m0peterson/d127)

Нажми кнопку, войди в Netlify, подтверди. Netlify сам скопирует репозиторий в твой GitHub и опубликует сайт. Сборка не нужна: сайт статический, настройки лежат в `netlify.toml`. Дальше каждый коммит в твою копию сам выкатывается на сайт.

## Как работает бросок

Два кубика бросаются за один тап, случайность берётся из `crypto.getRandomValues` без перекоса.

`слот = (страница - 1) * 3 + строка`

Получается ровно 127 × 3 = 381 слот, и в сборнике 381 цитата: у каждого исхода своя.

## Свои цитаты

Сборник лежит в [`public/data/quotes.txt`](public/data/quotes.txt): одна цитата на строку, порядковый номер строки и есть слот. Строки с `#` и пустые строки игнорируются. Если цитат меньше 381, пустые слоты берут цитату по кругу.

Чтобы заменить цитату, отредактируй строку прямо на GitHub и закоммить. Netlify перевыложит сайт. Старые посетители увидят новую версию со второго открытия (кэш обновляется в фоне).

## Генерация цитат через LLM

Шестерёнка в углу открывает настройки. Источник **LLM** сочиняет новую цитату на каждый бросок: кубики находят слот, цитата из слота становится темой, а модель пишет новую в духе твоих примеров. Задача у модели одна: тупо, смешно, кринжово и с серьёзным лицом.

Что настраивается:

- **Провайдер**: OpenRouter или мок (без сети, чтобы проверять интерфейс и не тратить деньги).
- **Ключ и модель**: ключ OpenRouter и название модели. Название копируй с openrouter.ai, подойдёт и slug, и ссылка целиком.
- **Примеры цитат**: поле плюс дропзона. Перетащи туда один или несколько `.txt` (на телефоне тапни по зоне и выбери файл), либо вставь текст руками. Нумерация, кавычки и подпись «— Джейсон Стэтхэм» убираются сами, дубликаты выкидываются, кодировка UTF-8 или Windows-1251 определяется автоматически. Размер файла до 1 МБ. В каждый запрос уходит 30 случайных примеров, поэтому большой список не раздувает счёт и даёт разнообразие.
- **Проверить генерацию** показывает результат и точный промпт, который уходит в модель (без ключа).

Если запрос к LLM упал (нет ключа, кончились деньги, неверная модель, нет сети), вместо молчания появится понятное сообщение, а на карточке останется цитата из сборника.

Текст промпта лежит в `SYSTEM_PROMPT` в [`public/js/llm.js`](public/js/llm.js), там же можно поправить тон. По умолчанию модель не использует мат, если его нет в примерах.

### Про ключи

Сайт статический, своего сервера и базы у него нет. Каждый посетитель вводит собственный ключ OpenRouter, и тот хранится только в `localStorage` его браузера. Запрос уходит прямо из браузера на `openrouter.ai`, через сайт ключ не проходит и никуда не логируется. Кнопка «Стереть ключи и настройки» чистит всё.

Что это значит для публичного сайта:

- Чужие ключи ты не видишь и не хранишь. Свой в код и в репозиторий не клади.
- Риск в XSS: пока на сайте нет инлайновых скриптов и стилей, CSP в `netlify.toml` разрешает отправку только на `openrouter.ai`. Не добавляй сторонние скрипты и не ослабляй CSP.
- Совет посетителям: заводить на OpenRouter отдельный ключ с лимитом расходов.

## Локальный запуск

```sh
python3 -m http.server -d public 8080
# или
npx serve public
```

Открой `http://localhost:8080`. Service worker работает только по HTTPS или на localhost.

## Структура

```
netlify.toml           публикация папки public, заголовки, CSP
public/
  index.html
  css/style.css
  js/app.js            интерфейс и бросок
  js/dice.js           d127 и d3
  js/quotes.js         загрузка сборника и поиск по слоту
  js/settings.js       localStorage, разбор примеров цитат
  js/llm.js            LLM-модуль: промпт, OpenRouter, мок
  data/quotes.txt      381 цитата
  sw.js                офлайн-кэш
```

## Дисклеймер

Цитаты в сборнике мемные и придуманы в духе Стэтхема. Это не слова актёра Джейсона Стэтхэма, он к ним не имеет отношения.
